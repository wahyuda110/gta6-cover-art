Neon Coast Cover Maker turns your own photos into a GTA-style multi-panel poster: load up to three photos, arrange them in three panel layouts, crop and position each panel, pick a sunset or neon colour grade, write a bold caption, and export a PNG in square, portrait, or wide post sizes — all offline, in the browser, with nothing uploaded.
## Run it
```sh
node serve.ts
```
Then open http://localhost:8080
